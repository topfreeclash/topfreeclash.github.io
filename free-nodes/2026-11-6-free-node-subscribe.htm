第三步：核心配置与模式选择

激活配置后，我们需要选择代理模式。Clash提供了三种核心模式，理解它们将帮助你更好地掌控网络流量：

  • 全局模式（Global）：所有网络请求都通过代理服务器转发。此模式速度最快，但会导致访问国内网站时速度变慢，且可能无法访问某些仅限国内IP的服务（如银行、视频网站的本地内容）。适合临时需要全部流量走代理的场景。
  • 规则模式（Rule）：这是最推荐的模式。Clash会根据内置的规则集自动判断流量走向。例如，访问Google、YouTube等国外网站时走代理，而访问百度、淘宝等国内网站时则直连。该模式智能高效，兼顾速度与便利性。
  • 直连模式（Direct）：所有流量均不经过代理。此模式下，Clash仅作为一个流量监视器。通常用于排查问题或仅需使用Clash的局域网共享功能时。

配置建议：日常使用中，请务必选择“规则模式”。在Clash for Windows中，你可以在主界面左侧点击“代理”（Proxies）标签页，然后在顶部的模式选择中切换。

第四步：节点选择与延迟测试

在“代理”（Proxies）页面，你会看到一组组策略组（如“手动选择”、“自动选择”、“全球加速”等）。点击“手动选择”组，会展开所有可用的节点列表。

  • 点击节点卡片右下角的“闪电”图标，可以对所有节点进行延迟测试。

四、进阶技巧：让1元Clash更好用

掌握了基础配置，你已经能正常上网了。但要想获得更极致的体验，以下进阶技巧不容错过。

技巧一：善用配置文件增强规则

虽然默认的订阅配置已经很智能，但你可能有更个性化的需求。例如，你想让某个特定的网站（如一个国外购物网站）走代理，但默认规则却让它直连了。

  • 在“配置”（Profiles）页面，右键点击你的订阅配置卡片，选择“编辑文件”（Edit File）。
  • 你会看到YAML格式的代码。找到rules:部分。
  • 在rules:下方添加一行：- DOMAIN-SUFFIX,shopify.com,你的代理策略组名。
  • 保存文件，Clash会自动热重载配置。这样，所有访问*.shopify.com的流量都会走你指定的代理。

技巧二：开启TUN模式，实现全局虚拟网卡

有时，某些应用（如游戏、特定软件）不走系统代理，导致无法科学上网。解决方法是开启Clash的TUN模式（虚拟网卡模式）。

  • 在Clash for Windows的“设置”（Settings）页面，找到“TUN Mode”开关并打开。
  • 首次开启时，系统会提示安装服务或驱动，点击确认即可。
  • 开启后，Clash会在系统中创建一张虚拟网卡，捕获所有网络流量，并按照你的规则进行转发。这能解决99%的应用不走代理的问题。

技巧三：定期更新订阅，保持节点活力

1元订阅的节点IP通常不稳定，可能被封锁或速度变慢。因此，定期更新订阅链接至关重要。

  • 在“配置”页面，右键点击订阅卡片，选择“更新”（Update）。
  • 建议设置定时自动更新。在“设置”->“订阅”中，可以找到“自动更新”选项，设置一个周期（如每24小时）。
  • 更新后，如果发现节点全部失效，请立即联系服务商获取最新链接。

技巧四：利用“规则”实现分流加速

国内访问国际网络，绕不开“绕路”问题。1元Clash的订阅通常默认使用“直连”策略访问国内网站。但如果你发现访问某些国内网站（如B站）速度慢，可能是因为规则匹配错误。

  • 在“代理”页面的策略组中，找到一个名为“国内媒体”或“直连”的组，确保其选择的是“DIRECT”。
  • 对于拥有IPv6环境的用户，可以在配置文件中增加ipv6: true，有时能改善特定网站的访问速度。

五、常见问题排查与解决指南

Q1: 订阅链接导入后，提示“无效的配置”或“下载失败”？

  • 检查网络是否能正常访问外网（可以先用手机热点测试）。
  • 检查订阅链接是否完整，不要有多余的空格。
  • 尝试在浏览器中直接访问该链接，看是否能返回一个文本文件。如果浏览器打不开，说明链接已失效，需联系卖家。

Q2: 节点全部显示超时（Timeout）？

  • 确认系统时间是否准确。时间偏差过大会导致TLS握手失败。
  • 尝试更换网络环境（如从WiFi切换到手机热点），排除本地网络封锁。
  • 过24小时后再试，可能是节点临时被墙。

Q3: 开启TUN模式后，无法访问局域网内设备（如打印机）？

  • 在TUN模式的设置中，勾选“绕过局域网”（Bypass LAN）或添加局域网IP段到直连规则。

Q4: 速度很慢，看视频卡顿？

  • 手动切换节点，选择延迟更低、负载更低的节点。
  • 尝试开启“自动选择”策略组。
  • 如果所有节点都慢，可能是服务商限速，或你的订阅套餐带宽已用完。

Q5: 使用1元Clash是否安全？

  • Clash本身是开源安全的。风险在于节点服务商。由于价格极低，服务商可能会记录你的访问日志。切勿在连接1元Clash时进行登录银行账户、输入信用卡密码等敏感操作。 建议仅在需要访问公开信息时使用。

FAQ

如何检查 Clash 连接失败的日志以定位问题？
打开 Clash 的日志面板或查看配置目录下的 log 文件，观察报错信息如 DNS 解析失败、节点拒绝连接或 TLS 握手错误。根据关键字（例如 timeout、refused、certificate）逐项排查并比对服务器配置。
Surfboard 是否支持应用分流？
支持。Surfboard 可通过策略组和规则文件将不同应用流量分配到指定节点，保证游戏、视频和浏览器流量走最优节点，提高访问速度和网络稳定性。
如何在 macOS 上运行 ClashX？
ClashX 是 macOS 平台专用客户端，用户可在 GitHub 下载 DMG 安装包。安装后导入订阅即可使用，支持系统代理集成、自动更新和延迟测试。界面简洁直观，深受苹果用户欢迎。
Potatso Lite 如何导入 URL 格式的订阅？
在 Potatso Lite 的配置页点击“导入”，粘贴订阅链接并确认导入。系统会自动解析节点列表，可在主界面查看并选择不同线路。部分机场支持一键导入格式，省去手动配置步骤。
Sing-box 的路由规则能否实现分国家代理？
Sing-box 支持 GeoIP 路由规则，通过引入国家数据库可根据 IP 自动判断地理位置。例如可设置 CN 走直连，US/JP 走代理，以此实现分国家策略路由，适合需要访问不同地区内容的用户。
WinXray 的测速功能不显示结果怎么办？
测速依赖于节点响应时间与服务器网络质量。若测速为空白，请检查系统时间同步、网络防火墙及代理端口设置是否正确；也可更新到最新版本修复已知测速模块异常问题。
Surfboard 可以结合规则实现广告屏蔽吗？
可以。Surfboard 支持通过规则文件匹配广告域名或 URL，将其阻断或重定向。结合策略组定期更新规则，可以实现自动广告屏蔽，提升网页浏览体验并节省带宽。
Clash 运行在低配设备上卡顿，如何减轻资源占用？
减少 rule-provider 数量、关闭不必要的日志与统计、降低 DNS 轮询频率并禁用内置测速；若使用 TUN 模式，可改为代理模式减少内核负担。必要时升级到更高性能的设备或使用更轻量内核。
Sing-box 能否直接读取 Clash 配置？
Sing-box 原生支持 Clash YAML 格式的导入，会自动解析成自身 JSON 结构。虽然部分脚本功能不兼容，但节点和规则可以正常使用，迁移过程非常平滑。
Mellow 的 TUN 模式与 SOCKS5 代理有什么区别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响支持代理的应用。TUN 更适合全局加速和游戏、视频等应用，保证所有流量通过节点，提高网络稳定性。
